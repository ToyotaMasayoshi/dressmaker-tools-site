# Dressmaker Tools

Free fan-made guide & tools site for **Dressmaker**, the cozy sewing sim by Cozy Lives / Free Lives (Steam).

🔗 **Live site: https://dressmaker-tools.com/**

## What's inside

- **Fabric Finder** — all 564 fabrics, with where to find each one → https://dressmaker-tools.com/fabrics/
- **Pattern Finder** — 178 patterns catalogued and searchable
- **Accessories Catalog** — 445 accessories
- **Characters & Commissions** — 10 characters, 88 commissions with requirement walkthroughs
- **Dress Planner** — sketch your dress and check attribute totals before you cut → https://dressmaker-tools.com/dress-planner/
- **Guides** — commission walkthroughs, mechanics explainers → https://dressmaker-tools.com/guides/commission-walkthrough/

## About this repo

This repo is the public home of the project: roadmap, changelog and issue tracker for the site. The site itself is a static build; contributions, corrections and feature ideas are welcome via Issues.
